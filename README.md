# Каталог косметики

## Описание проекта (ТЗ)
Приложение представляет собой графический каталог косметики, разработанный на Python с использованием библиотеки PySide6 и базы данных SQLite. 

**Основные возможности:**
*   Просмотр списка товаров в виде таблицы.
*   Фильтрация товаров по категориям и поиск по названию.
*   Добавление, редактирование и удаление товаров.
*   Загрузка и отображение изображений товаров (мультимедиа).
*   Добавление товаров в «Избранное» (с визуальной отметкой ⭐).
*   Просмотр подробной карточки товара.

## Технологии
*   **Язык:** Python 3
*   **Библиотека интерфейса:** PySide6 (Qt for Python)
*   **База данных:** SQLite3 (встроенная)
*   **Среда разработки интерфейса:** Qt Designer

## Структура проекта
*   `main.py` — точка входа, запуск приложения и настройка стилей (цвета, кнопки).
*   `logic/` — папка с бизнес-логикой:
    *   `database.py` — класс `DatabaseManager` для работы с БД (чтение, запись, изменение, удаление).
    *   `main_window.py` — логика главного окна (таблица, поиск, фильтры).
    *   `product_dialog.py` — логика формы добавления/редактирования.
    *   `product_view.py` — логика карточки просмотра товара.
*   `ui/` — папка с дизайном (файлы `.ui` из Qt Designer и сгенерированные из них `.py` файлы).
*   `assets/` — папка для хранения изображений товаров.
*   `data/` — папка с файлом базы данных `cosmetics.db` (создается автоматически).


## Как пользоваться программой
1. **Просмотр и поиск:** При запуске открывается главное окно с таблицей всех товаров. Сверху можно выбрать категорию (фильтр) или ввести название товара в поле «Поиск».
2. **Добавление товара:** Нажмите кнопку «Добавить». В открывшемся окне заполните название, выберите категорию, укажите цену и описание. Нажмите «Выбрать картинку», чтобы загрузить фото товара. Нажмите «Сохранить».
3. **Редактирование:** Выберите товар в таблице и нажмите «Редактировать». Измените нужные поля и сохраните.
4. **Просмотр карточки:** Сделайте двойной клик по строке с товаром, чтобы открыть карточку с большой фотографией и подробным описанием.
5. **Избранное:** Выберите товар и нажмите «В избранное». У товара появится звездочка ⭐.
6. **Удаление:** Выберите товар и нажмите «Удалить».


## Установка и запуск

Для запуска проекта необходимо создать виртуальное окружение.

1. Клонируйте репозиторий и перейдите в папку:
      bash
   git clone https://github.com/sssmariii/semestr_python
   cd semestr_python

2.  Создайте виртуальное окружение: 
  python -m venv venv

3.  Активируйте виртуальное окружение 
   Для Windows:
   venv\Scripts\activate

4.  Для MacOS / Linux:
   source venv/bin/activate

5.  Установите необходимые зависимости:
   pip install -r requirements.txt

6.  Запустите приложение:
    python main.py
